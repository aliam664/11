# آموزش فعال معادله‌ی درجه دوم (نسخه‌ی ۳)

سایت فارسی (RTL) برای یادگیری: معادله‌ی درجه دوم، جمع و ضرب ریشه‌ها (S و P)، سهمی و مدل‌سازی، صفرهای تابع و تغییر متغیر.

## روش آموزش (هر درس ۷ مرحله)
1. **مثال حل‌شده** گام‌به‌گام؛ قبل از بعضی گام‌ها «حدس بزن گام بعد چیست؟»
2. **مفهوم و تعریف رسمی** (استخراج از مثال)
3. **چرا؟** دلیل هر گام + مقایسه‌ی روش‌ها + اشتباهات رایج
4. **پیش‌نیازها**: سؤال کوتاه + مرور هدفمند و لینک به درس پایه
5. **حل مشارکتی**: مسئله‌ی مشابه، یک سؤال در هر مرحله، راهنمایی تدریجی (جای اشتباه ← کوچک ← بزرگ‌تر)، بازخورد هدفمند برای اشتباه‌های رایج و «نشانم بده» به‌عنوان آخرین راه
6. **تمرین پلکانی**: متوسط ← دشوار
7. **ارزیابی واقعی**: آزمون واحد و آزمون نهایی با سؤال تازه و بدون راهنمایی

مثال‌های ترکیبی: مثال حل‌شده + یک مسئله‌ی مشابه.

## تسلط و مرور
- درصد تسلط هر درس از کیفیت حل (مستقل / با راهنمایی / با دیدن پاسخ) محاسبه می‌شود.
- مرور فاصله‌دار (لایتنر: ۱۲ ساعت، ۱، ۳، ۷، ۱۴، ۳۰ روز).
- ذخیره‌ی پیشرفت در `localStorage` با کلید `quad-v3`.

## فایل‌ها
- `index.html`، `css/style.css`
- `js/engine.js` موتور یادگیری (بررسی پاسخ، راهنمایی، تسلط، مرور)
- `js/practice.js` سؤال‌های هر درس، `js/assess.js` آزمون‌ها
- `js/content*.js` متن درس‌ها، `js/data.js` فرمول‌نامه، `js/tools.js` ابزارها، `js/app.js` مسیریابی و صفحه‌ها
- `build.js` ساخت `standalone.html` (تک‌فایل، آفلاین): `node build.js`

اجرای محلی: `python3 -m http.server 8000`

## مسیر سه درس اول فصل یک

از گزینهٔ «سه درس اول فصل یک» به درس‌نامه‌های مجموع دنباله‌ها، درجه دوم و معادلات گویا و گنگ دسترسی دارید. کارگاه شامل ۱۵ مسئله و ۴۷ گام با راهنمایی و نمایش اختیاری پاسخ است؛ آزمون ۶ سؤال مستقل دارد. پیشرفت هر مسئله فقط پس از اتمام آن ذخیره می‌شود و از تسلط مسیر قدیمی جداست. بازنشانی کلی، هر دو مسیر را پاک می‌کند. آزمون داده‌ها: `node mathsite/tests/chapter-data.test.js` از ریشهٔ مخزن. منابع در انتهای هر درس ذکر شده‌اند.
